## 🚀 How to Use

### Running a Solution
```bash
python scripts/run.py topics/05_arrays/two_sum.py
```
You'll be prompted to enter input. Press `Ctrl+D` (or `Ctrl+Z` on Windows) when done.

### Scaffolding a New Problem
```bash
python scripts/new_problem.py
```
Follow the prompts to create a new solution file with the template pre-filled.

## 📝 Problem File Naming

Name files descriptively: `<problem_id>_<short_description>.py`

Examples:
- `1234A_beautiful_array.py`
- `987B_two_sum.py`

Each file contains the problem link, constraints, approach, and solution.
